## 🎯 Sobre o Curso

Este repositório contém todo o material teórico e prático do curso de **Estatística para Análise de Dados**. O objetivo principal é ensinar como aplicar conceitos estatísticos fundamentais na resolução de problemas reais de negócios e análise exploratória usando **Python**.
