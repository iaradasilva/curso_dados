O que é o Software R?

O R é uma linguagem e ambiente de programação de código aberto (gratuito) focado em computação estatística, análise de dados e gráficos. É amplamente utilizado na área da saúde, epidemiologia e bioestatística devido ao seu poder de processamento e ecossistema de pacotes especializados.

💡 Por que usar o R?
O R permite realizar desde análises descritivas básicas até a modelagem de regressão e séries temporais com dados de saúde pública de forma 100% reproduzível.

Principais Vantagens do R na Saúde

  • Gratuito e Código Aberto: Pode ser instalado em qualquer sistema operacional sem custos de licença.
  • Reprodutibilidade Científica: Todo o fluxo de análise é registrado em scripts, garantindo que qualquer pesquisador consiga replicar os resultados.
  • Pacotes Especializados: Milhares de bibliotecas criadas pela comunidade para epidemiologia, saúde pública e estatística espacial (como tidyverse, epidemia, sf e survival).
  • Visualização de Dados: Capacidade de gerar gráficos de alta qualidade para artigos científicos e relatórios públicos.

O R e o RStudio

Para trabalhar com o R de forma mais intuitiva, utilizamos o RStudio (Posit), que é a Interface de Desenvolvimento Integrado (IDE) para a linguagem:

  • R (O "Motor"): Executa os cálculos estatísticos e processa os dados.
  • RStudio (O "Painel"): Facilita a escrita do código, visualização de gráficos, tabelas e organização de projetos.

Instalação

Para configurar o seu ambiente de trabalho, siga a ordem de instalação:

  1. Baixe e instale o R base diretamente do CRAN: cran.r-project.org ↗
  2. Baixe e instale o RStudio Desktop: posit.co/rstudio ↗
⚠️ Nota: Instale sempre o R base antes do RStudio para que a interface identifique o programa corretamente.

Primeiro Exemplo Prático em R (Dados de Saúde)

Copie e cole o código abaixo no console do RStudio para testar seu ambiente e rodar sua primeira análise descritiva com visualização gráfica:

# 1. Verificar versão do R
print(paste("Ambiente configurado:", R.version.string))

# 2. Criar um pequeno conjunto de dados de saúde fictício
dados_saude <- data.frame(
  id_paciente = 1:5,
  idade = c(45, 62, 35, 58, 50),
  pressao_sistolica = c(120, 142, 118, 135, 128),
  grupo_risco = c("Baixo", "Alto", "Baixo", "Médio", "Médio")
)

# 3. Exibir a tabela de dados no console
print("--- Tabela de Pacientes ---")
print(dados_saude)

# 4. Calcular a média de idade e pressão sistólica
media_idade <- mean(dados_saude$idade)
media_pressao <- mean(dados_saude$pressao_sistolica)

cat("\nMédia de Idade:", media_idade, "anos\n")
cat("Média da Pressão Sistólica:", media_pressao, "mmHg\n")

# 5. Gerar um gráfico simples
barplot(
  height = dados_saude$pressao_sistolica,
  names.arg = paste("P", dados_saude$id_paciente),
  col = "#10B981",
  main = "Pressão Sistólica por Paciente",
  xlab = "Pacientes",
  ylab = "Pressão (mmHg)"
)

Instalação e Configuração do Ambiente R

Para acompanhar o curso Análise de Dados e Modelagem Estatística Aplicada à Saúde (Projeto O3 MOVER), é necessário instalar dois programas gratuitos e de código aberto: o R Base e a IDE RStudio (Posit).

⚠️ Regra de Ouro da Instalação: Instale SEMPRE o R Base primeiro e depois o RStudio. Se inverter a ordem, o RStudio não conseguirá localizar o motor do R.

1. Cartões de Download Direto

Clique nos botões abaixo para acessar as páginas oficiais de download correspondentes:

Baixar o R (CRAN) ↗
🔷

A interface visual (IDE) que facilita a escrita de scripts, gráficos e relatórios.

Baixar RStudio Desktop ↗

2. Passo a Passo de Instalação

Para Usuários de Windows 🪟

  1. Acesse o site do CRAN e clique em "Download R for Windows".
  2. Clique em "base" e depois em "Download R 4.x.x for Windows".
  3. Execute o instalador baixado e avance clicando em Avançar / Next (pode manter todas as configurações padrão).
  4. Em seguida, baixe o RStudio Desktop for Windows e execute o instalador até a conclusão.

Para Usuários de Mac (macOS) 🍎

  1. Acesse o site do CRAN e clique em "Download R for macOS".
  2. Escolha o arquivo .pkg adequado para o processador do seu Mac:
    • Apple Silicon (M1/M2/M3/M4): Baixe a versão arm64.
    • Processador Intel: Baixe a versão x86_64.
  3. Execute o arquivo baixado para instalar o R Base.
  4. Por fim, baixe o RStudio Desktop for macOS, abra o arquivo .dmg e arraste o ícone do RStudio para a sua pasta Aplicativos.
💡 Dica de Ferramenta Alternativa (Sem Instalação):
Caso precise usar um computador institucional onde não possui permissão de administrador para instalar programas, você pode usar gratuitamente o Posit Cloud (RStudio na Nuvem) ↗ diretamente pelo navegador.

3. Testando e Instalando os Pacotes Principais do Curso

Com o RStudio aberto, você precisa instalar os pacotes essenciais que usaremos ao longo das aulas. Copie o código abaixo e cole no seu Console do RStudio:

# 1. Testar se o R está funcionando
cat("Ambiente R funcionando na versão:", R.version.string, "\n")

# 2. Instalar os pacotes essenciais para Saúde e Bioestatística
pacotes_curso <- c(
  "tidyverse",  # Manipulação de dados e gráficos (ggplot2, dplyr)
  "readxl",     # Leitura de planilhas Excel
  "janitor",    # Limpeza e padronização de tabelas
  "epidemia",   # Pacote para modelagem de doenças infecciosas
  "sf"          # Análise e dados de saúde espacial
)

# Comando para baixar e instalar no RStudio
install.packages(pacotes_curso)
