Módulo 1: Introdução à Análise de Dados Exploratória (EDA)

Bem-vindo ao curso de Estatística Aplicada. Nesta lição, exploraremos a base de todo projeto de dados: a Análise Exploratória de Dados (EDA), e como começar.

O que é EDA?

A Análise Exploratória de Dados é uma abordagem para analisar conjuntos de dados com o objetivo de resumir suas principais características, frequentemente usando métodos visuais.

  • Coleta de dados precisos e estruturação.
  • Visualização de tendências centrais e dispersões.
  • Identificação de outliers e padrões.
  • Resumo estatístico e relatórios automatizados.

Primeiros Passos

Para começar com EDA em Python, você precisa instalar as bibliotecas base: pandas, numpy e scipy.
